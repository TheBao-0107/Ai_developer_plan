# 第 2–3 个月：后端基础（2026.12 ～ 2027.1）

> 这是你最大的短板，也是后面所有项目的地基。**宁可慢，不要跳。**
> 共 9 周（第 5–13 周），每周 10 小时
> 主线练习：用 9 周时间，把一个"待办清单 API"从零做到上线

---

## 本阶段要学会什么

| 技能 | 为什么要学 |
|---|---|
| Python 进阶（类型标注、async 异步、装饰器） | FastAPI 和大模型 SDK 大量使用这些语法 |
| HTTP 协议 | 所有 API 都基于它，面试必问 |
| Linux 命令行 | 部署服务、看日志都离不开 |
| FastAPI | 目前 AI 应用后端最主流的 Python 框架 |
| SQL 和 MySQL | 存储业务数据 |
| 用户认证（JWT） | 几乎每个产品都需要 |
| Redis | 缓存、会话存储；后面也会用来存对话历史 |
| Docker | 打包和部署的标准方式；Agent 的代码沙箱也要用到 |

## 第 5 周：Python 进阶（一）

| 天 | 内容 |
|---|---|
| 周一 | **类型标注**：`def add(a: int, b: int) -> int`、`list[str]`、`dict[str, int]`、`Optional` |
| 周二 | **模块和包**：`__init__.py`、相对导入、项目目录结构 |
| 周三 | **uv**：创建项目 `uv init`、加依赖 `uv add`、运行 `uv run` |
| 周四 | **推导式**：列表、字典、集合推导式；`lambda`；`sorted(key=...)` |
| 周五 | **dataclass**：用 `@dataclass` 简化数据类 |
| 周末 | 用类型标注、dataclass 和 uv 重构记账本，加上 `pyproject.toml` |

## 第 6 周：Python 进阶（二）

| 天 | 内容 |
|---|---|
| 周一 | **装饰器**：原理（函数也是对象），自己写一个计时装饰器 |
| 周二 | **上下文管理器**：`with` 的原理，自己写一个 |
| 周三 | **生成器**：`yield`。大模型流式输出就是用生成器实现的 |
| 周四 | **async/await（一）**：为什么需要异步，事件循环的直觉 |
| 周五 | **async/await（二）**：`asyncio.gather` 并发执行多个任务 |
| 周末 | 练习：用 `httpx` 异步库并发抓取 10 个网页的标题，对比同步和异步的耗时 |

> async 一开始难理解很正常。先记住一句话：**等待网络（比如等大模型回复）的时候，程序可以去做别的事。** 后面用多了自然会懂。

## ✅ 第 2–3 个月检验标准

一个完整的**待办清单 API**，满足：
- [ ] 用户注册、登录（JWT）
- [ ] 待办的增删改查、分页、筛选，每个用户只能看到自己的数据
- [ ] 数据存在 MySQL，列表接口有 Redis 缓存
- [ ] `docker compose up` 一键启动全部服务
- [ ] 部署在云服务器上，公网能访问 `/docs` 页面
- [ ] GitHub 上有清晰的 README
- [ ] 代码里没有任何明文密码或密钥

**并且能口头讲清楚：** 一个请求从浏览器发出，到返回结果，中间经过了哪些步骤。

## ⚠️ 安全提醒

- **永远不要把密码、API Key 提交到 GitHub。** 用 `.env` 文件存放，并把 `.env` 写进 `.gitignore`。
- 已经提交过的密钥，即使后来删掉，在 Git 历史里依然能找到。一旦泄露，要立刻作废并重新生成。
- 下个月开始用大模型 API，Key 泄露会直接造成经济损失，这个习惯现在就要养成。
