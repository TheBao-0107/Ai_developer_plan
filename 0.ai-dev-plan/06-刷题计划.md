## 每次 1 小时怎么用

| 时间 | 做什么 |
|---|---|
| 前 10 分钟 | **复习：** 重写一道之前做过的题（优先选 ★ 题和做错过的题） |
| 中间 40 分钟 | **新题：** 读题 5 分钟 → 想思路 15 分钟 → 没思路就看题解 → 看懂后**关掉题解自己写** |
| 最后 10 分钟 | **记录：** 在笔记里写下题号、一句话思路、易错点 |

### 笔记格式

```markdown
## 1. 两数之和 ★
- 思路：用哈希表存"值 → 下标"，遍历时查找 target - x 是否已经在表里
- 复杂度：时间 O(n)，空间 O(n)
- 易错点：要先查找再存入，否则同一个元素会被用两次
- 日期：2027-02-02 第一次 ✅ / 2027-02-09 复习 ✅
```

### 常见的坑

```python
# ❌ 错误：三行其实是同一个列表，改一行会改到全部
grid = [[0] * 3] * 3

# ✅ 正确
grid = [[0] * 3 for _ in range(3)]
```

递归太深会报错：Python 默认的递归深度限制大约是 1000，必要时用 `sys.setrecursionlimit(10**6)` 调高。

## 面试时怎么做题

1. **先确认题意：** 复述一遍题目，问清边界情况（数组会不会为空？有没有负数？）
2. **先说思路，再写代码：** 先讲暴力解法，再讲优化思路，说出时间和空间复杂度
3. **边写边讲：** 让面试官知道你在想什么
4. **写完自己测试：** 用一个普通例子和一个边界例子，手动走一遍代码

**不会做的时候：** 不要沉默。把你想到的思路说出来，哪怕是暴力解法。面试官经常会给提示。
