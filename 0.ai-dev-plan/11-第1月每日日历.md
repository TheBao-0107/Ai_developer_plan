### W1D1 说明（第一天，特殊）

2026-11-02 检查时，**Python 3.14.7、VS Code、Git 都已安装，Git 用户名和邮箱已配置，GitHub 仓库已存在**（就是本项目）。所以第一天不需要从零安装，任务是**验证 + 补齐 + 跑通第一个程序 + 第一次提交**：

1. **验证环境**（把命令输出粘贴到 task.md）：`python --version`、`where python`（确认用的是 `D:\myApp-Python\...` 那个，而不是 `WindowsApps` 里的占位程序）、`git --version`、`git config --global user.name`
2. **VS Code**：确认装了 Python（微软官方）和 Pylance 插件；用 VS Code 打开 `D:\Code\Ai_developer_plan` 文件夹；左下角或右下角选对 Python 解释器
3. **两种运行方式**：在终端输入 `python` 进入交互模式，执行 `print("Hello")` 后退出（`exit()`）；再写一个 `.py` 文件，分别用终端 `python 文件名.py` 和 VS Code 运行按钮运行
4. **小编程题 1–2 道**：只用 `print()`，例如输出一个简单的自我介绍卡片或 ASCII 图案，要求输出和示例**逐字符一致**（练习细心和读报错）
5. **"故意制造错误"小任务**：故意写错一处（漏引号、括号不配对、`Print` 大写），运行后把报错的最后一行粘贴进 task.md，用自己的话解释报错的意思
6. **第一次提交**：照着命令做 `git add` → `git commit -m "W1D1: 环境和第一个程序"` → `git push`（周五会系统学习 Git，今天只需照做）
7. 不出"看代码说结果"题也可以。总时长控制在 60 分钟以内

> 原计划 `01` 文件写的是"新建 `python-learning` 仓库"。现在统一改为：**练习代码放在本项目的 `1.python_learning/` 目录下**，不再单独建仓库。
