# ChatGPT 使用指南

> 你接下来主要用 ChatGPT 学习。这份文件包括：完整的背景说明、各种场景的提示词模板、使用原则

---

## 一、先设置好背景

**如果你的 ChatGPT 有"项目（Projects）"功能：** 新建一个项目，比如叫"AI 应用开发转型"，把下面的背景说明粘贴进项目指令。以后在这个项目里开新对话，它都会自动带上这些背景。

**如果没有：** 把背景说明放进"自定义指令"，或者每次开新对话时先发一遍。

### 背景说明（完整版）

```
【我的情况】
- 非计算机专业，按零专业基础算
- 自学过一点 C++，Python 零基础，LeetCode 刷过但已经忘了
- 工作经历：Android CameraHal 实习（主要是抓日志、分析 Trace、测试）；鸿蒙端侧开发 + 项目 PM；大模型 Coding 评测
- 每周能学 10 小时：工作日每晚 1 小时，周末 5 小时
- 在杭州

【我的目标】
转型 AI 应用开发工程师（偏 Agent 方向），不做算法岗。计划 2027 年 5 月开始投简历。

【8 个月学习计划】
- 第 1 个月（2026.11）：Python 基础，用《Python 编程：从入门到实践》
- 第 2–3 个月（2026.12–2027.1）：后端基础，包括 Python 进阶（类型标注、async）、HTTP、Linux、FastAPI、SQL/MySQL、SQLAlchemy、JWT 认证、Redis、Docker、部署。练习项目是带登录功能的待办清单 API
- 第 4 个月（2027.2）：大模型 API，包括流式输出、结构化输出、Function Calling、提示词设计，以及 Transformer 原理。用 DeepSeek 或通义千问的 API
- 第 5–6 个月（2027.3–4 月中）：RAG + 项目一"技术文档问答助手"（FastAPI 文档作为知识库，pgvector、混合检索、重排序、评测集、实验记录）
- 第 6–8 个月（2027.4 月中–6）：Agent + 项目二"数据分析 Agent"（先手写 ReAct 循环，再用 LangGraph 重构；MCP Server；Docker 沙箱；复用项目一的检索模块查数据字典；评测和失败案例分析）
- 第 4 个月起：每周二、周四晚上刷 LeetCode Hot 100
- 第 7 个月起：准备面试、投简历

【请你这样帮我】
1. 当我的导师，不要替我写代码。我问问题时，先给提示和思路，让我自己写；我明确说"给我答案"时才给完整代码
2. 讲概念时，先讲直觉和类比，再讲细节。我有 C++ 基础，可以拿 C++ 来类比
3. 我发代码时，帮我 review：指出问题和改进方向，让我自己改
4. 涉及框架和库的用法（尤其是 LangGraph、MCP、各家大模型 API），提醒我以官方文档为准，因为你的知识可能过时
5. 不确定的内容请直接说不确定，不要编造
6. 回答尽量简洁，用中文
```

## 二、保持进度连续：每周进度记录

ChatGPT 不一定记得你之前的对话。建议在 GitHub 仓库里维护一个 `progress.md`，每周日更新，开新对话时把最近一周的记录贴给它。

```markdown
## 第 X 周（日期）
- 本周学了：
- 完成了：
- 卡在：
- 下周计划：
- 进度：正常 / 落后 X 天 / 提前
```

## 三、提示词模板

### 1. 学一个新概念

```
我今天要学【概念，比如：Python 的装饰器】。
请先用一个生活中的类比讲直觉，再讲它解决了什么问题，最后给一个最简单的例子。
讲完后出 2 道小练习给我，先不要给答案。
```

### 2. 卡住了，要提示

```
我在做【任务】，卡住了。
我的思路是：【你的思路】
我卡在：【具体哪里】
我的代码：【代码】
请只给我一个提示，指出我该往哪个方向想，不要给完整代码。
```

### 3. 排查报错

```
我的代码报错了。
代码：【代码】
完整报错：【报错信息，全部贴上】
我自己猜的原因是：【你的猜测】
请告诉我猜得对不对，并解释报错信息该怎么读。让我自己改。
```

> **一定要先写下自己的猜测再问。** 这一步能训练你读报错的能力。

### 4. 代码 review

```
请 review 这段代码。我是初学者，希望你从这几个方面看：
1. 有没有 Bug 或边界情况没处理
2. 代码风格是否符合 Python 惯例
3. 结构是否清晰，有没有可以简化的地方
4. 有没有安全问题（比如密钥、SQL 注入）
只指出问题和方向，按重要程度排序，不要直接给我改好的代码。
【代码】
```

### 5. 出题考我

```
我刚学完【主题】。请出 5 道题考我：
- 2 道概念题（问我"为什么"）
- 2 道看代码说结果的题
- 1 道小编程题
一次只出一道，等我回答后再评分并讲解，然后出下一道。
```

### 6. 月底考核

```
今天是第 X 个月的月底考核。这个月我学了：【内容】
检验标准是：【贴上对应文件里的检验标准】
请你：
1. 用 5 个问题考我的概念理解，一次问一个
2. 我会贴上我的项目代码和 README，请对照检验标准逐条检查
3. 最后告诉我：能不能进入下个月？如果不能，需要补哪些内容，大概补几天？
```

### 7. 讨论项目设计

```
我在做【项目一 / 项目二】，现在要设计【某个模块，比如：切分策略】。
我的想法是：【你的方案】
请你：
1. 指出我方案的优缺点
2. 给出 1–2 个替代方案，并说明各自的取舍
3. 问我几个我可能没考虑到的问题
不要直接替我做决定。
```

### 8. 模拟面试：技术面

```
请你扮演一名杭州 AI 公司的面试官，面试"AI 应用开发工程师"岗位。
面试范围：【比如：计算机网络 + Redis + RAG 原理】
规则：
- 一次只问一个问题，等我回答
- 根据我的回答追问 1–2 层，就像真实面试一样
- 不要提示我答案
- 一共问 8 个问题，结束后给我打分（满分 10 分），并指出我回答中最大的 3 个问题
```

### 9. 模拟面试：项目深挖

```
请你扮演一名严格的技术面试官，深挖我的项目。
这是我的项目 README：【贴上 README】
规则：
- 先让我用 3 分钟介绍项目
- 然后针对技术选型、难点、数据、不足之处连续追问，每个点追问到我答不上来为止
- 结束后告诉我：哪些地方讲得好，哪些地方暴露了问题，以及我需要补哪些知识
```

### 10. 模拟面试：HR 面

```
请你扮演 HR，面试我。重点问：离职原因、为什么转行、非科班背景、职业规划、期望薪资。
每个问题等我回答后，告诉我这样回答会给 HR 什么印象，以及怎么改进。
```

### 11. 修改简历

```
这是我的简历：【简历内容】
目标岗位是这个 JD：【JD 内容】
请帮我：
1. 指出简历和 JD 之间的差距
2. 指出哪些描述太空泛、缺少数字
3. 指出哪些地方可能会被面试官深挖，提醒我准备
注意：不要帮我编造或夸大经历，只帮我把真实经历表达得更好。
```

### 12. 分析 JD

```
这是一个"AI 应用开发 / Agent 开发"岗位的 JD：【JD 内容】
请帮我判断：
1. 这是真正写代码的开发岗，还是用 Coze / Dify 配置的岗位？依据是什么？
2. 要求的技能里，按我的学习计划，哪些我已经会了，哪些还没有？
3. 这个岗位适不适合我投？
```

### 13. 进度落后，调整计划

```
我的计划落后了 X 周，原因是：【原因】
当前进度：【进度】
剩下的计划：【贴上剩余计划】
请帮我调整：哪些内容可以压缩，哪些绝对不能省，哪些可以放到找到工作以后再学。
```

## 四、使用原则

### ✅ 要做的

- **先自己想，再问。** 卡住 20–30 分钟再问，问的时候带上你自己的思路。
- **让它解释"为什么"。** 不只要知道怎么做，还要知道为什么这样做。面试考的就是这个。
- **用它来考你。** 学完就让它出题，被考到不会的地方，才是你真正没掌握的地方。
- **用语音模式练面试。**

### ❌ 不要做的

- **不要让它直接写项目代码。** 项目是你面试时最重要的证明，每一行都要能讲清楚。
- **不要完全相信它。** 尤其是这几类：
  - 框架和库的用法（LangGraph、MCP、FastAPI 的新版本）→ **以官方文档为准**
  - 模型名称、价格、接口地址 → 去官网核实
  - 招聘市场、薪资情况 → 去 Boss 直聘自己看
- **不要贴敏感信息：** API Key、密码、公司内部的代码和数据。

### 判断它是不是在"编"

- 它给的函数名或参数，在官方文档里搜不到
- 代码一运行就报 `AttributeError` 或 `ImportError`（常见原因是库的版本变了）
- 让它给出处时，给不出具体的文档链接

遇到这些情况，直接去查官方文档或 GitHub 上的 issues。
