## C++ 转 Python 的注意事项

你学过 C++，下面这些地方最容易写错：

| 主题 | C++ 的习惯 | Python 的做法 |
|---|---|---|
| 代码块 | 用 `{}` | 用**缩进**（统一 4 个空格），缩进错了就是语法错误 |
| 变量类型 | 声明时写类型 | 不用声明，直接赋值；类型标注第 2 个月再学 |
| 自增 | `i++` | 没有 `++`，要写 `i += 1` |
| 除法 | `7 / 2` 等于 3 | `7 / 2` 等于 3.5；整除要写 `7 // 2` |
| for 循环 | `for (int i = 0; i < n; i++)` | `for i in range(n):`；遍历列表直接写 `for x in lst:` |
| 同时要下标和值 | 手动维护下标 | `for i, x in enumerate(lst):` |
| 逻辑运算 | `&&` `\|\|` `!` | `and` `or` `not` |
| 空值 | `nullptr` | `None`，判断时写 `x is None` |
| 赋值语义 | 默认是拷贝 | **默认是引用**。`b = a` 后修改 `b` 列表，`a` 也会变；需要拷贝时用 `a.copy()` |
| 数组 | 固定长度 | 列表长度可变，可以放不同类型的元素 |
| 字符串 | 可以修改 | **不可修改**，每次"修改"都会生成新字符串 |
| main 函数 | `int main()` | `if __name__ == "__main__":` |

### 一个经典的坑：默认参数用可变对象

```python
# ❌ 错误：所有调用共享同一个列表
def add_item(item, lst=[]):
    lst.append(item)
    return lst

# ✅ 正确
def add_item(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst
```

## 学习方法

1. **书里的每个例子都自己敲，不复制粘贴。** 手敲是建立肌肉记忆最快的方法。
2. **报错时先自己读报错信息。** Python 的报错从下往上读：最后一行是错误类型，往上是出错的位置。
3. **卡住 20–30 分钟再问 ChatGPT，并且让它只给提示、不给完整代码。** 提示词模板见 `08-ChatGPT使用指南.md`。
4. **每周日晚上花 10 分钟回顾：** 这周学会了什么，哪里还不懂，记在 GitHub 仓库的 `notes.md` 里。
