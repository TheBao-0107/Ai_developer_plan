## 目录约定

```
week01/
├── day1/                 ← 周一（day1=周一 … day7=周日）
│   ├── task.md           ← AI 出的题 + 我填写的答案和小结
│   ├── examples.py       ← 手敲的书上例子
│   ├── ex1_xxx.py        ← 练习题
│   └── review.md         ← AI 批改
├── …
├── day6/  day7/          ← 周末：只放 task.md 和 review.md
└── project_scores/       ← 周末项目代码
```

| 周 | 周末项目目录 |
|---|---|
| 第 1 周 | `week01/project_scores/`：成绩统计程序 |
| 第 2 周 | `week02/project_ledger_v1/`：记账本 v1 |
| 第 3 周 | `week03/project_ledger_v2/`：记账本 v2（函数 + 类） |
| 第 4 周 | `week04/project_ledger_v3/`：记账本 v3（JSON + 异常 + 测试），**月度检验** |

## 运行

在本项目根目录打开终端：

```bash
python 1.python_learning/week01/day1/ex1_xxx.py
```

或在 VS Code 里打开文件，点右上角的 ▶ 运行。
