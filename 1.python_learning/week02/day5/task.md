### 练习 1（基础）：筛选旅途交通账　→ `ex1_travel_transport.py`

**要求：**

1. 用一个列表保存下表的四笔账，每笔是一个独立字典。字段为 `category`（类别）、`amount`（整数金额）、`note`（备注），按表格顺序保存。

   | 类别  | 金额  | 备注         |
   | --- | --- | ---------- |
   | 交通  | 6   | 地铁         |
   | 餐饮  | 24  | 午饭         |
   | 交通  | 4   | 不创建 note 键 |
   | 购物  | 15  | 明信片        |

2. 遍历账目，只输出交通账的明细；缺少备注时显示“未备注”，不要给原字典补键。

3. 循环结束后，输出交通账的笔数与总额。结果应从数据计算，不能直接打印写死的统计值。

4. 本题不用输入。若没有交通账，应只输出“交通合计：0笔，0元”。

**示例输出：**

```text

交通：4元，未备注
交通合计：2笔，10元
```

**验收：**

- [x] 四笔账均保存，明细只显示两笔交通账。
- [x] 缺少备注时不报错，原字典仍然没有 note 键。

### 练习 2（基础）：累计支出小菜单　→ `ex2_expense_menu.py`

**针对：输入提示换行、字符串选项判断，以及循环的正常退出。**

**要求：**

1. 程序启动时累计支出为 0。用 while 重复显示菜单，每轮菜单固定为一行：

   ```text

   ```

2. 显示“请选择：”并读取选项：

   - 输入 `1`：显示“请输入金额（正整数）：”，再读取金额、转换并累加，打印“已记录”。本题只需保存累计金额，不要求保存逐笔明细。

### 练习 3（看代码说结果 / 找 Bug）：为什么输入 0 没有退出？

先独立推断，再运行核对。这段代码只执行一次判断。

```python
choice = input("请输入选项：")
if choice == 0:
    print("退出")
else:
    print("继续")
```

**问题：**

1. 用户输入 `0` 并按回车后，分支打印什么？只写“退出”或“继续”对应的实际输出，不用抄输入提示。
2. 比较时，两边分别是什么类型？这个比较会报错，还是得到一个布尔结果？
3. 如果还允许输入 `x` 等其他字符，不要求数字转换，应怎样调整判断才能识别退出选项？只用文字说明。

**我的答案：**

分支输出：

```text
继续
```

- 两边的类型与比较结果：choice是字符串，0是int，会得到一个布尔结果，始终为False
- 调整方向：if choice == '0'，把判断条件改写成这样即可
