**针对：字符串方法的返回值与列表元素的更新。**

日志标签混有大小写和首尾空格。你要保留原始记录，在副本上清理，再判断哪些标签需要处理。

**要求：**

1. 原始列表为 `[" ERROR ", "Info", " warning ", "debug"]`。其中第 1、3 个字符串的首尾各有一个空格。
2. 用切片创建副本。用循环处理副本中的每个字符串：去掉首尾空白、转成小写，并把处理结果存回副本相应位置。不能直接写出清理后的完整列表，原始列表要保持不变。

info：无需处理
