### 练习 2（基础）：连续记录支出　→ `ex2_expense_input.py`

### 练习 3（看代码说结果 / 找 Bug）：为什么循环结束不了？

先独立推断下面的代码，不要直接长时间运行。如果运行后一直不结束，在终端按 Ctrl+C 停止。

```python
number = 1
while number <= 3:
    if number == 2:
        continue
    print(number)
    number += 1
print("结束")
```

**问题：**

1. 不手动中断时，程序已经打印了哪些内容？是否会打印“结束”？原样输出写在下面代码块中，解释写在外面。
2. 程序之后是否还能改变 number？指出导致该现象的执行路径。
3. 如果希望跳过数字 2 的输出，同时正常完成循环，应怎样调整更新的位置或执行顺序？只用文字说明，不要求写修改后的代码。

**我的答案：**

程序原样输出：

```text
1
```

- 是否打印“结束”：不会
- 执行路径与原因：第一次进入循环，走到第5行打印1，走到第6行number变成了2，第二次进入循环，走到第4行，又会重新进入循环，不会走到下面的+1逻辑
- 调整方向：第3行和第4行之间，也就是在continue之前，number += 1
