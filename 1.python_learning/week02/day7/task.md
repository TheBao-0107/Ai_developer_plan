选 `1` 后，先检查金额文本，再做数字转换。本版只接受大于零的整数元；练习数据用日常金额。输入 `abc`、空行、`0`、`-3` 或 `2.5` 时，提示「金额无效」，**取消这一笔并直接返回主菜单**，不再追问类别、备注或日期。类别和备注本次使用非空文本，日期原样保存，不要求验证日期格式。

**字符串方法小提示：** 可以先在 Python 交互窗口分别试 `'27'.isdecimal()`、`'2.5'.isdecimal()` 和 `''.isdecimal()`。想一想：如果输入的是 `'0'`，除了检查字符，你还要判断什么？

- [ ] 逐一试过上述五个无效金额；每次都能回菜单，账本笔数不变，也不会出现「已记录」。
