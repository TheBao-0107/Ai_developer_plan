### 练习 1（基础）：三笔生活账　→ `ex1_daily_records.py`

为周末记账本准备数据，用**列表里放字典**保存账目。

**要求：**

1. 先创建一个列表，里面放两个独立的字典，数据如下。金额均为整数。

   | 日期（键 `date`） | 类别（键 `category`） | 金额（键 `amount`） | 备注（键 `note`）   |
   | ------------ | ---------------- | -------------- | -------------- |
   | 2026-11-11   | 餐饮               | 12             | 早餐             |
   | 2026-11-11   | 交通               | 3              | 这笔不创建 `note` 键 |

2. 用 `append()` 追加第三笔：日期 `2026-11-11`，类别 `餐饮`，金额 `18`，备注 `晚餐`。第三笔也要用独立的字典表示。

3. 打印标题，再用一个 `for` 循环按列表顺序打印全部账目。字段之间使用一个空格、竖线、一个空格，即 ` | `。

4. 用 `get()` 读取备注；缺少 `note` 键时显示“无备注”，保留原字典没有此键的状态。

5. 遍历时累加金额；循环结束后打印笔数和总支出。笔数从列表长度获得，总支出必须计算。

**示例输出（要逐字符一致）：**

```text
账目明细
2026-11-11 | 餐饮 | 12元 | 早餐
2026-11-11 | 交通 | 3元 | 无备注
2026-11-11 | 餐饮 | 18元 | 晚餐
共3笔
总支出：33元
```

**验收：**

- [x] 使用一个列表保存三笔字典数据，第三笔通过 `append()` 添加。
- [x] 使用循环读取数据、累加金额；标题和最后两行统计各打印一次。
- [x] 交通账目缺少 `note` 键，程序仍正常运行，并且查询没有新增该键。
- [x] 运行 `python 1.python_learning/week02/day3/ex1_daily_records.py`，六行输出与示例一致。
- [x] **针对：命名与空格。** 变量使用小写加下划线；逗号和字典键值分隔冒号后有空格；嵌套代码每层缩进 4 个空格。
