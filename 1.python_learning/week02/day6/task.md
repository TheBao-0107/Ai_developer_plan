### 看代码说结果（约 5 分钟）：两次添加是否就是两笔独立记录？

先推断，再在 examples.py 中验证，不要把实验代码放进记账本程序。

```python
record = {"金额": 18, "类别": "餐饮"}
entries = [record]
record["金额"] = 6
record["类别"] = "交通"
entries.append(record)
print(len(entries))
print(entries[0]["金额"], entries[1]["金额"])
```

1. 两行输出分别是什么？
2. 列表里是否有两个独立的字典？用自己的话解释。
3. 如果要保留原来的餐饮账，用一句话说明录入下一笔时应注意什么，不要求写修正代码。

**我的答案：**

- 第一行输出：2
- 第二行输出：6，6
- 是否独立及原因：题里的列表有两个位置，但两个位置指向同一个字典
- 录入下一笔时应注意：如果沿用同一个变量名，每次录入都新建字典，前一笔会受影响吗？不会。因为新建字典后，即使用的还是同一个变量名，也指向不同的数据（也就是新建的那个字典）了。
