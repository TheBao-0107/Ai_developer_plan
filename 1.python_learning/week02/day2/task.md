### 练习 1（基础）：更新相机配置　→ `ex1_camera_config.py`

用一个字典保存相机配置。初始数据如下，键是字符串，值的类型按表中说明填写：

| 键       | 初始值     | 值的类型 |
| ------- | ------- | ---- |
| `mode`  | `photo` | 字符串  |
| `fps`   | `30`    | 整数   |
| `debug` | `True`  | 布尔值  |

**要求：**

1. 先从字典中直接读取 `fps`，打印初始帧率。
2. 在同一个字典中把 `fps` 改为 `60`，新增 `resolution`，值为字符串 `1920x1080`，再用 `del` 删除 `debug`。
3. 直接读取并打印当前的 `mode`、`fps` 和 `resolution`，顺序与示例一致。
4. 用 `get()` 查询尚不存在的 `storage`，指定默认文字为 `未配置`，打印查询结果。不要向字典新增这个键。
5. 最后用 `len()` 输出当前配置项数。数值和配置内容必须来自字典或查询结果，不能直接把整份示例输出写死。

**示例输出（要逐字符一致，共 6 行）：**

```text
初始帧率：30
模式：photo
更新帧率：60
分辨率：1920x1080
存储路径：未配置
配置项数：3
```

**验收：**

- [x] 初始配置确实保存在一个字典中，且在原字典上完成新增、修改、删除。
- [x] `debug` 已删除，`storage` 没有被新增。
- [x] 已存在的配置按键直接访问，缺失的配置用 `get()` 查询。
- [x] 运行无报错，完整 6 行输出与示例逐字符一致，最后的数量通过计算得到。

<details><summary>提示（卡住 10 分钟再看）</summary>

先输出旧值，再修改；同一个键只对应一个当前值。新增键与更新已有键的写法很接近。查询缺失配置时，查书确认 `get()` 的第二个参数有什么作用；最后数一数字典中实际剩下了哪些键。

</details>

### 练习 2（基础）：相机模块超时报告　→ `ex2_timeout_report.py`

**针对：循环和条件分支的嵌套缩进、逗号后的空格及英文名称拼写。**

创建一个字典，按以下顺序写入三个模块及超时次数：

| 模块（字符串键）  | 超时次数（整数值） |
| --------- | --------- |
| `preview` | 2         |
| `capture` | 0         |
| `encode`  | 4         |

**要求：**

1. 用 `items()` 和一个 `for` 循环同时取出模块名与次数。按初始写入顺序输出，今天这道题不排序；Python 字典会保留键的插入顺序。
2. 在循环内用 `if/else` 判断：次数大于 `0` 时标记为 `需检查`，否则标记为 `正常`。每个模块只打印一行。
3. 循环结束后，用 `values()` 和 `sum()` 计算所有模块的超时总次数，只打印一次总计。
4. 不要逐个模块写死判断或结果。检查循环体、条件分支内语句、循环外总计语句各自的缩进位置。

**示例输出（要逐字符一致，共 4 行）：**

```text
preview：2 次，需检查
capture：0 次，正常
encode：4 次，需检查
超时总次数：6
```

**验收：**

- [x] 使用 `items()` 遍历键值对，用条件判断产生状态文字。
- [x] 总次数来自字典的值，且总计只输出一次。
- [x] 每层缩进 4 个空格，两层嵌套为 8 个空格；三处模块名与表格拼写一致。
- [x] 完整 4 行输出与示例逐字符一致；数字与“次”之间有一个空格，逗号为中文 `，`。
- [x] 自测：临时把 `encode` 的次数改为 `0`，它应显示“正常”，总次数应变为 `2`；验证后恢复为 `4`。

<details><summary>提示（卡住 10 分钟再看）</summary>

`items()` 提供键和值，`values()` 只提供值。先理清层次：逐个模块的工作在循环内，状态判断在循环内再分支，总计在循环结束后。输出不对时，先检查打印语句属于哪一层。

</details>
