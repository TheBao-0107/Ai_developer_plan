### 练习 1（基础）：相机模式卡片　→ `ex1_camera_mode.py`

相机日志里的一段模式文字是 `"  nIGHT  "`，开头和结尾各有 **2 个普通空格**。

**要求：**

1. 用变量保存这段原始文字，并保留它不变。
2. 用字符串方法得到去掉两端空格后的文字，另外保存处理结果。
3. 用字符串方法分别得到全大写、全小写的模式文字。
4. 用 f-string 输出下面 3 行。原始文字两侧的方括号用于显示空格位置，整理后的两行不带这些多余空格。

**示例输出（要逐字符一致）：**

```text
原始模式：[  nIGHT  ]
整理后模式：NIGHT
采集提示：night
```

**验收：**

- [x] 恰好输出 3 行，没有额外说明或空行；标签后的冒号是中文冒号 `：`。
- [x] 第一行的方括号内保留原来的大小写和两端各 2 个空格。
- [x] 后两行通过字符串方法得到，没有直接把 `NIGHT`、`night` 写成结果。
- [x] 使用了 f-string；原始文字和处理后的文字分别保存。
- [x] 写法符合本日范围。

### 练习 2（基础）：采集帧数统计　→ `ex2_capture_stats.py`

**B. 找出名称错误（针对：定位运行时的名称错误并说明原因）：**

```python
frame_count = 12
print("采集开始")
print(f"帧数：{Frame_count}")
print("采集结束")
```

从第一行赋值语句开始数，回答下面的问题。只需解释和描述修改方向，不必在这里写修正后的代码。

**我的答案：**

- 第一次报错发生在第几行：3

- 前面实际赋值的名字是：frame_count
- 这是语法问题还是执行时的问题？为什么：执行时的问题，语法没有错误，执行时找不到对于的变量名了
- 最后一行会执行吗？为什么：不会，执行时发生错误，程序终止了
- 我打算如何修改：把"F"改成"f"
