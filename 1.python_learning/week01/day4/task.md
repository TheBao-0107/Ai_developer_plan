#### 3A：修改会影响谁？

**针对：直接赋值是否会复制列表。**

```python
modes = ["photo", "video"]
linked = modes
saved = modes[:]
linked.append("night")
print(modes)
print(saved)
```

问题：两行分别输出什么？`linked`、`saved` 与 `modes` 的关系有什么区别？说明为什么一次追加会产生这样的结果。

**我的答案：**

- 第一行预测：['photo', 'video', 'night']
- 第二行预测：['photo', 'video']
- 原因：linked和modes都指向原["photo", "video"]这个数据，两者同时修改。saved只是原来modes的一个拷贝副本，不会跟着改
- 运行验证与订正（先预测后填写）：验证通过

#### 3B：负数怎样整除？

**针对：区分向下取整、四舍五入和直接去掉小数部分。**

```python
print(-13 / 4)
print(-13 // 4)
```

问题：写出每行输出及结果类型（整数或浮点数）。第二行采用哪一种取整规则？请用第一行的商和它两侧的相邻整数说明理由，不能只写“因为用了 `//`”。

**我的答案：**

- 第一行预测及类型：-3.25 浮点数
- 第二行预测及类型：-4 整数
- 取整规则及理由："//"运算符是向下取整，往更小的那个整数取整。第一行的商是“-3.25”，靠近"-4"和"-3"，取小的，也就是"-4"
- 运行验证与订正（先预测后填写）：正确
