一：项目做什么
1.用途：该程序用于统计并打印成绩报告
2.已有功能：
可以根据原始成绩列表，统计出：总人数，平均分，最高分，最低分，及格人数等数据结果并打印
可以将原始成绩列表按照降序逐个打印。

二：怎么运行
1.需要先检查是否有python环境，通过py 命令运行本程序
2.在proje_scores目录下打开终端，执行py .\scores.py命令即可运行该程序
3.运行示例：
=== 成绩统计报告 ===
原始成绩：[88, 59, 76, 100, 60, 92, 45, 83, 60, 97]
人数：10
平均分：76.0
最高分：100
最低分：45
及格人数：8
--- 降序成绩 ---
第1位：100
第2位：97
第3位：92
第4位：88
第5位：83
第6位：76
第7位：60
第8位：60
4.当前限制：
暂不支持键盘输入源数据，暂不支持保存数据，暂未考虑到数据量较大时的场景
