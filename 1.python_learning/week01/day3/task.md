#### 3A · 排序之后，打印的分别是什么？

```python
frame_rates = [24, 60, 30]
result = frame_rates.sort()
print(result)
print(frame_rates[-1])
```

问题：写出两行输出，并分别说明 `result` 保存了什么、第二行取的是排序后哪个位置的元素。

**我的答案：**

- 两行输出预测：

```text
[24, 30, 60]
60
```

- 第一行的原因：result保留了frame_rates排序后的拷贝
- 第二行的原因：-1访问的是列表最后一个值也就是len(frame_rates)-1下标位置，此时已经被排序
- 运行验证与订正：第一行错了，.sort()方法没有返回值，正确结果是None
