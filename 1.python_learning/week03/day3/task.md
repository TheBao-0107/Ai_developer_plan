### 练习 3（看代码说结果）· 哪些字会出现在屏幕上？

假设下面两个文件在同一目录。每条命令都从终端单独启动一次 Python。先预测，再核对。

`doorbell.py`

```python
def ring():
    print("叮咚")

print("门铃就绪")
if __name__ == "__main__":
    ring()
```

`visitor.py`

```python
from doorbell import ring as notify

print("访客到达")
notify()
```

分别写下运行 `python doorbell.py` 和 `python visitor.py` 的逐行输出。第二条命令中，哪一行代码让门铃响了？为什么？

**我的答案：**

- 直接运行门铃文件的输出（逐行填写）

```text
门铃就绪
叮咚
```

- 运行访客文件的输出（逐行填写）

```text
门铃就绪
访客到达
叮咚
```

- 我的解释：notify()这行代码让门铃响了，因为它实际时doorbell文件中的ring函数，只不过被as换了个名字。运行访客文件之所以第一行会先打印门铃就绪，是因为import先于print("访客到达)，import相当于把对应模块中的代码完整拷贝到了本文件的import位置，而打印“门铃就绪”的代码并没有放在if判断中，自然就会执行了。
- 首次导入时，会执行print("门铃就绪")然后执行if判断为False。访客文件中的notify指向门铃文件中的ring方法。
