### 练习 3（看代码说结果）· 为什么提示音变了？

```python
class Speaker:
    def __init__(self):
        self.volume = 2

    def preview(self, volume):
        volume += 1
        print(volume)

hall = Speaker()
hall.preview(4)
print(hall.volume)
```

先写下两行输出，再解释：调用 `hall.preview(4)` 时，`self` 指向谁？方法里被加 1 的是哪一个值？用它解释第二行。最后可在交互模式核对。

**我的答案：**

```text
5
2
```

我的解释：调用hall.preview(4)时，self指向hall本身，此时属性volume的值就是默认的init方法中的值为2；方法里被加1的时传入的4，临时变量。传入的4并没有赋给self.volume，因此第11行打印结果还是原来的2
