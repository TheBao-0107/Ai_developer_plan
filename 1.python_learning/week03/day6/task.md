## 二、项目练习（25 分钟）

回程时想看看这趟出门花了多少钱。用同一个 `Record` 类创建三笔开销，按表中的顺序记进同一本账。

| 金额（元） | 类别  | 备注   | 日期         |
| ----- | --- | ---- | ---------- |
| 18    | 交通  | 去程车票 | 2026-11-20 |
| 32    | 餐饮  | 午饭   | 2026-11-20 |
| 12    | 交通  | 回程地铁 | 2026-11-21 |

**针对：接收调用者已经创建的实例。** 在同一个 `models.py` 里完成 `Ledger`。三个方法的约定如下。

| 方法                      | 调用者能用它做什么                        |
| ----------------------- | -------------------------------- |
| `add()`                 | 传入一笔已经创建好的 `Record`，把这个实例记进当前账本。 |
| `list_all()`            | 拿到按记入顺序排列的记录列表。空账本返回空列表。         |
| `summary_by_category()` | 拿到一个字典，键是类别，值是该类别的总金额。空账本返回空字典。  |

**运行自查。** 在 `models.py` 的直接运行入口写一个小演示，用方法返回的数据打印三行明细和两项合计。在项目目录运行 `python models.py`。对照数值、字段和明细顺序，分类合计的先后顺序不限。
