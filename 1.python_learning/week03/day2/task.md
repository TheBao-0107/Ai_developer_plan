### 练习 3（看代码说结果）· 两次默认调用之间

旅店希望每位客人都有一张独立的叫醒单。先在纸上或下方预测三行输出，再运行核对。

```python
def book_alarm(room, rooms=[]):
    rooms.append(room)
    return rooms

print(book_alarm("301"))
print(book_alarm("205", []))
print(book_alarm("408"))
```

哪几次调用使用了同一个列表？第二次调用会影响第三行吗？如果希望每次省略清单时都从空单开始，你会把创建新列表的时机放在哪里？

**我的答案：**

```text
第一次和第三次调用了同一个列表，第二次调用不会影响第三行，我会放到函数内部，而不是给参数默认缺省值。
```

- 理由和修改思路：每次都新建一个新的变量，就不会有指向同一个变量的风险了

  ```python
  def book_alarm(room, rooms):
      if not rooms:
          rooms = []
      rooms.append(room)
      return rooms
  ```
