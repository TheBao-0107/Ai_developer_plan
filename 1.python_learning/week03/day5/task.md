### 练习 3（看代码说结果，5 分钟）· 取号机什么时候出声？

**针对：首次导入时的执行顺序，以及导入的名字指向什么。** 假设下面两个文件在同一目录，你在新开的 Python 进程里运行 `python counter.py`。

`chime.py`

```python
class Chime:
    def call(self):
        print("请到窗口")

print("取号机就绪")
if __name__ == "__main__":
    print("取号机自检")
```

`counter.py`

```python
from chime import Chime as Bell

print("窗口开放")
bell = Bell()
bell.call()
```

先写出终端的逐行输出。再说明第一行来自哪个文件的哪条语句、`Bell` 在窗口文件里指向什么，以及哪条语句让机器喊出「请到窗口」。

**我的答案**

```text
取号机就绪
窗口开放
请到窗口
```

我的解释：第一行来自chime.py文件的第五行。Bell在窗口文件里指向Chime类，语句bell.call()让机器喊出请到窗口
